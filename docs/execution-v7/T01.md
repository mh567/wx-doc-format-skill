# T01 手工编号标题：去编号保标题

依赖：无。本包唯一工单。

## 背景

见 `README.md`。定案方向为用户 2026-09-16 裁定的 A（去编号保标题）。

## 工作项

### 1. 角色优先级

`scripts/wxdf/semantics/structure.py` 的 `collect_structure_candidates` 调整分支顺序：显式标题（含文档标题）样式先裁决；受保护分支只在样式未给出角色时决定角色。文本型受保护理由仍写入角色候选的附加证据，供决策账本追溯。

带角色的受保护结论（`note`、`numbered_note`、`code_block`、公式原子）保持原优先级。判据来源为 `note_semantics.source_note_role`，不动它的规则。

### 2. 标题文本清理

同一模块新增内容候选：已定级标题且 `text_utils.strip_heading_marker(text)` 与原文不同时，发布 `update_node_content`，写入去标记后的 `inline_content`。标记只在段首出现一次，沿用词表既有行为。

去标记后 `inline_text_projection` 为空时：不发布内容候选，源文本保留，产出 `heading_marker_only_text`（info）降级记录。

作用范围：`role == "heading"` 的块。文档标题（`role == "title"`）本包不改，理由记入残留。

### 3. 治理文档同步

定案后把两条规则写入 `AGENTS.md` 决策 10：显式标题样式先于文本型受保护理由；已定级标题的交付文本不含手工标记，标记词表归 `text_utils.strip_heading_marker` 单一所有者。
