# 本包证据约定

每个工单一份 `T<nn>.md`，内容固定为四节：

1. **红灯**：未改实现时的测试计数与逐项失败清单，附命令。
2. **绿灯**：实现后的专项与全量计数，附命令。
3. **样例矩阵**：逐份输入类型（DOCX / Markdown / 真实文档）的实测结果，写明状态、三项审计、`unexpected_styles`、`risk_warnings`，以及与本工单相关的逐段输出事实（样式名与文本）。
4. **独立审查与复审**：Standards 轴与 Spec 轴各一条结论列表，逐条标注已修 / 记录为残留 / 需用户裁定，附复审后的计数。

证据只记录实际命令的实际输出。任何未实测的推断必须显式标注为未验证，并按 `AGENTS.md` 的「诚实核算覆盖」原则处理，不允许把未覆盖写成已覆盖。

未关闭项在证据文件中单列，并同步回 `status.json` 的 `residuals`。本包状态唯一源是 `../status.json`。
