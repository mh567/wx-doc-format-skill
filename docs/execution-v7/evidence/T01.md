## 实现中发现并处理的冲突

1. **L11 验收边界**：`tests/test_issue4_acceptance.py` 的 L11 要求 API 标签、日期版本这类受保护文本在标题样式下仍保持 `body`。规格初稿写「所有文本型理由让位于显式标题」，落地按验收收窄为只让 `manual_heading_marker` 让位。规格的解决方案与字段级定义已按实现改写。
2. **影子等价审计的隐含假设**：`semantics/equivalence.py` 的 `_candidate_roles` 假设每节点只有一条候选并取最后一条，新增内容候选使该假设失效（角色被读成内容载荷，等价审计报 `role_mismatch`）。已改为只认带 `role` 的候选，并补登归属表。该函数无生产调用方。
3. **规格自相矛盾**：规格正文写「去标记只作用于 `role == "heading"`」，验收清单第 11 项要求 Markdown 首个 H1 成为「文本无标记」的文档标题。按验收清单实现（`heading` 与 `title` 都去标记，且与已退役的 Markdown 读取器一致），规格正文该行已改写。
