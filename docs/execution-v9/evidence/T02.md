## 实测

**真实文档**输出的附录各级标题：

| 样式 | 直接 outlineLvl | 文本 |
|------|----------------|------|
| 附录标题 | `0` | （资料性）附录示例 |
| 附录一级标题 | 无 | 章小四号黑体不加粗，行间距1.25倍，段前、段后各0.5行 |
| 附录二级标题 | 无 | 条小四号黑体不加粗，行间距1.25倍 |
| 附录三级标题 | 无 | 条小四号黑体不加粗，行间距1.25倍 |

按模板的目录域 `TOC \o "1-3"`：附录标题（直接级别 0）→ 目录第 1 级；附录一级标题（样式级别 1）→ 第 2 级；附录二级标题（样式级别 2）→ 第 3 级；附录三级标题（样式级别 3）→ 第 4 级，在域范围之外。与模板和源文档的目录缓存（1 / 2 / 3，无第 4 级）一致。

**报告**：`status=completed_with_warnings`、`model_audit`、`saved_output_audit`、`appendix_preservation_audit` 均通过，`unexpected_styles=[]`，`risk_warnings` 为空。

**本机不可验证**：目录条目的最终层级与附录分页需要用户在 Word/WPS 中打开确认，登记为外部门禁 `word_toc_and_appendix_page_manual_check`。本机只能验证写出的直接大纲级别与文档顺序。

## 未关闭

- legacy 诊断链路的 `\t` 映射与 `toc_contract.TOC_CUSTOM_STYLE_LEVELS`（附录标题为 2）保持原样，只服务诊断链路；若 legacy 用于交付，该映射需要按裁定 A 另行调整。
- 附录一级至三级标题仍依赖模板样式的大纲级别；若将来替换模板且其附录样式级别不同，需要重新核对。
- `outline_level` 在 `presentation.outline` 与 `presentation.paragraphs` 两处含义不同（前者选样式、后者写直接属性）。已在 `normalization._paragraph_presentation` 的 docstring 说明；独立审查建议可另起键名，本包未改（改名会牵动正文大纲合同）。
