# T03 原生 LLM EnhancementExecutor

## 分工

Codex 固定能力和 Patch 合同；Claude 实施；Codex 审查及复审。

## 范围

- `scripts/wxdf/enhancement.py`
- `scripts/wxdf/legacy_capability.py`
- `scripts/wxdf/resolver.py`
- `scripts/wxdf/transaction.py`
- `scripts/main.py`
- 对应测试与证据

## 工作

将本地命令和受控在线 Adapter 接入 native EnhancementExecutor。四项能力只读取版本化视图，输出 CandidateSet 或 Patch，经 Resolver 和 TransactionManager 提交。

## 验收

`modular_online` 开放；无响应、超时、无效 Patch、陈旧目标、预算耗尽和能力缺失均返回稳定状态；同一执行不进入 legacy；普通模式回归无网络访问。
