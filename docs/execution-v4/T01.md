# T01 加深 Module 并收口 Kernel

## 分工

Codex 固定 Interface 和 Seam；Claude 实施；Codex 审查及复审。

## 范围

- `scripts/wxdf/kernel.py`
- `scripts/wxdf/registry.py`
- `scripts/wxdf/builtin_modules.py`
- `scripts/wxdf/semantics/`
- 对应测试与证据

## 工作

把解析、范围、结构、列表、附录、表格和题注候选生成移入真实注册 Module。Kernel 只构建上下文、执行计划并收口结果。删除转发预计算值的浅层 Module。

## 验收

Kernel 不含领域识别调用；每个 Module 通过自身 Interface 合同测试；Registry 缺失、顺序、版本和失败策略测试通过；真实输入报告证明各 Module 真实产出并被消费。
