# T07 薄 Skill、公开报告和平台合同

## 分工

由 Command Code 协同多个智能体实施；Skill 契约由架构智能体设计，实施、生成与测试由一个智能体承担，独立审查与复审由另一个智能体承担。

## 范围

- `SKILL.md`
- `packaging/nuitka/public/`
- `packaging/nuitka/public-repo/`
- `packaging/nuitka/assemble_public_skill.py`
- 报告脱敏、manifest 和测试

## 工作

确定单一 Skill 规范源，生成在线薄 Skill 和离线包版本。Skill 只保留触发、模式、命令、审计、停止条件和人工复核。建立稳定公开报告摘要及 accepted、candidate、unavailable 平台状态。

## 验收

三个 Skill 产物无语义漂移；公开命令进入 native-v2；Windows 不再声明为发布目标；Kylin 候选状态由 manifest 和 launcher 一致消费；公开树无私有 Python 文件。
