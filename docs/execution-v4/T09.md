# T09 编译分发与完整验收

## 分工

由 Command Code 协同多个智能体实施；门禁与发布决策由架构智能体定案，本地制品实施与测试由一个智能体承担，独立审查与复审由另一个智能体承担。

## 范围

- Nuitka 构建与冒烟流程
- `dist/local/` 候选制品
- `dist/public-skill/` 生成树
- 验收证据

## 工作

从同一私有提交构建 macOS ARM64 和 Kylin V10 ARM64 候选制品，验证在线薄 Skill、离线安装、普通模式、LLM 文件协议、恢复、复核、报告脱敏和真实 DOCX。

## 验收

源码与编译制品能力清单一致；全量测试、真实转换、ZIP、安装、ASCII 路径和公开 Skill 校验通过；Kylin 真机保持外部门禁；远程推送、标签、Release 和安装同步等待用户授权。
