# T05 原生审计后复核与候选发布

## 分工

由 Command Code 协同多个智能体实施；接受策略由架构智能体定案，实现由一个智能体承担，独立审查与复审由另一个智能体承担。

## 范围

- `scripts/wxdf/review.py`
- `scripts/wxdf/auditing.py`
- `scripts/wxdf/publication.py`
- `scripts/wxdf/transaction.py`
- 对应测试与证据

## 工作

把 ReviewPacket、候选修订、重渲染、复审、接受和回滚接入 native 事务链。基线和候选使用独立暂存产物，Publisher 只发布被接受版本。

## 验收

`modular_review` 开放；内容变化、新增高风险、评分无改善和审计异常均回滚；接受后目标 finding 消失；失败不替换正式输出。
