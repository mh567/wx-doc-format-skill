## 实现边界

1. 根 `SKILL.md` 收敛为公开可执行规范源，仅保留触发、模式、平台启动、命令、审计、停止条件和人工复核。
2. `packaging/nuitka/public/SKILL.md` 与 `packaging/nuitka/public-repo/SKILL.md` 为根规范的字节一致快照。
3. 在线组装和离线包组装均直接复制根 `SKILL.md`，测试同时检查源码快照和生成产物字节。
4. 公开在线目标仅含 `macos-arm64` 与 `kylin-v10-arm64`。Windows required 参数返回 `ValueError`，公开树不再包含 PowerShell launcher 或 Windows 目标声明。
5. 在线与离线 manifest 均声明 `public_summary` 合同。在线 manifest 的 `platforms` 映射是 available 与 unavailable 兼容字段的唯一派生来源。
6. 在线和离线 POSIX launcher 均在缓存、下载或 runtime 执行前读取当前平台状态。macOS accepted 继续，Kylin candidate 输出 `WXDF-W-RUNTIME-CANDIDATE` 后继续，unavailable、缺失、未知和损坏状态以退出码 3 停止。
7. release 报告保留递归脱敏兼容行为，并增加 `schema_version=1.0` 的路径无关 `public_summary`。摘要固定包含 status、pipeline、profile、list_policy、audits、unexpected_styles_count、manual_review_required 和 diagnostic_codes。
8. `packaging/nuitka/build_distribution.py` 的历史 Windows 构建入口保持原状，T07 未将其纳入公开发布门禁。

## 平台状态矩阵

| 平台 | 制品条件 | 状态 | launcher 行为 |
| --- | --- | --- | --- |
| macOS ARM64 | 制品存在且 minos 有效 | accepted | 继续 |
| macOS ARM64 | 制品缺失或 minos 缺失 | unavailable | 退出码 3 |
| Kylin V10 ARM64 | 制品存在 | candidate | 稳定告警后继续 |
| Kylin V10 ARM64 | 制品缺失 | unavailable | 退出码 3 |
| Windows x86_64 | 公开组装 required | 不属于公开目标 | `ValueError` |

有制品的平台状态条目包含 name、sha256 和 size。`AVAILABLE_PLATFORMS.txt`、available_platforms 与 unavailable_platforms 均按同一状态映射生成。
