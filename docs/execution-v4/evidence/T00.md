## 真实转换

全部产物位于 `/tmp/wxdf-t00-evidence/`。

夹具：`/tmp/wxdf-t00-evidence/fixture.docx`，由 `python-docx` 生成，包含 Heading 1 标题、正文段落、两条 `List Number` 有序列表、2x2 表格和一张行内 PNG 图片。

命令：

```bash
scripts/.venv/bin/python3 scripts/main.py \
  --input input/test_baseline.md \
  --output /tmp/wxdf-t00-evidence/md-legacy.docx \
  --template assets/wx_template.docx \
  --pipeline legacy --list-policy legacy --llm-enhance off \
  --report /tmp/wxdf-t00-evidence/md-legacy-report.json \
  --source-ast /tmp/wxdf-t00-evidence/md-legacy-source.json \
  --ast /tmp/wxdf-t00-evidence/md-legacy-normalized.json

scripts/.venv/bin/python3 scripts/main.py \
  --input input/test_baseline.md \
  --output /tmp/wxdf-t00-evidence/md-native.docx \
  --template assets/wx_template.docx \
  --pipeline modular --modular-profile native-v2 --list-policy wx-default-v2 --llm-enhance off \
  --report /tmp/wxdf-t00-evidence/md-native-report.json \
  --source-ast /tmp/wxdf-t00-evidence/md-native-source.json \
  --ast /tmp/wxdf-t00-evidence/md-native-normalized.json
```

DOCX 对照命令同上，把 `--input` 换成 `/tmp/wxdf-t00-evidence/fixture.docx`，输出换成 `docx-legacy` 与 `docx-native`。

| :--- | :--- | :--- | :--- | :--- | :--- |
| md-legacy | 0 | legacy 报告无 `status` 键 | 不适用 | `1.0` | 不适用 |
| md-native | 0 | `completed` | `true` | `2.0` | `true` |
