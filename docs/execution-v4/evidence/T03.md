## 实现边界

- `EnhancementExecutor` 增加 AST 2.0 版本化只读视图、CandidateSet 2.0 与 Patch 2.0 校验、响应候选提取和稳定故障状态。
- 原生候选聚合在同一阶段收集四项已注册能力的增强候选，随后统一进入 `Resolver` 和 `TransactionManager`。
- `modular_online` 已开放，CLI 只接受用户显式提供的本地 `--llm-command`。程序化 adapter 只通过 `ConversionRequest.options["enhancement_call"]` 显式注入。
- `--llm-enhance off` 不解析 adapter，也不执行命令。环境自动发现、URL、凭据和网络后端未接入 native-v2。
- `Patch 2.0` 的直接 decisions 只用于合同与新鲜度校验。候选仍由 Resolver 重新裁决，最终写入由 TransactionManager 单次提交。
