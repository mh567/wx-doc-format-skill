# T08 移除发布运行时 legacy 表面

## 分工

Codex 审定删除清单；Claude 实施；Codex 审查及复审。

## 范围

- `scripts/wxdf/legacy_*`
- 旧 parser、normalizer、review 与 renderer 的生产调用点
- `packaging/nuitka/build_distribution.py`
- `packaging/nuitka/smoke_distribution.py`
- 对应测试与证据

## 工作

删除发布运行时中的 legacy pipeline、legacy-full-v1、旧模式 manifest 和无生产用途桥接。确有旧数据迁移需求的代码收口为独立迁移工具，不进入正常转换执行计划。

## 验收

编译模块清单无 legacy 生产入口；运行时只有新模式；源码调用图和测试证明正常转换不会导入旧主链；历史检查点获得明确迁移或拒绝结果。
