# Skill 新架构完整切换执行包

## 目标

将公开 Skill、源码 CLI、LLM 增强、检查点恢复、审计复核和编译分发统一切换到 native-v2 主链，并从发布运行时移除 legacy 生产路径。

## 执行规则

1. `status.json` 是本执行包的唯一状态源。
2. 工单按 T00 至 T09 串行执行，只有卡片明确允许时才并行。
3. Codex 负责架构、编排、审查、验收和 Git；Claude 负责具体实施和测试。
4. 每张工单先建立红灯，再实现，再由 Codex 审查；审查发现交 Claude 修复，Codex 复审后才可标记 `done`。
5. 每张工单在 `evidence/Txx.md` 记录命令、退出码、测试结果、真实转换和审查结论。
6. `_build/`、`paseo.json` 及无关改动保持原状。
7. 远程推送、标签、Release、公开仓库更新和安装副本同步需要独立授权。

## 完成定义

无参数公开调用进入 native-v2；普通、命令增强、文件请求、恢复和审计复核均使用 AST 2.0 与同一事务主链；Kernel 只负责编排；发布制品不携带 legacy 生产入口；源码、编译制品和公开 Skill 的能力清单一致；全量测试、真实 Markdown、真实 DOCX、安装及分发冒烟全部通过。
