## 修改

1. DOCX 解析保留分页与分栏类型，沿用 `kind=break`，增加可选 `break_type=page|column`；缺省换行保留旧表示。校验接受兼容表示并拒绝非法类型。正文、超链接与题注按类型渲染，并列条款只按普通换行拆分。
2. 题注按行内 AST 安全消费源标签和编号，正文使用通用行内渲染，保留粗体、链接、制表符、书签、字段、公式与分页。附录题注保留源编号和行内结构。模板的 SEQ 标识符与可见标签分别表达，缓存文本与实际可见标签一致。
3. 渲染映射携带重建后的行内审计合同。审计合并相邻文本以容忍 run 分段差异，同时继续检查链接目标、顺序与分页类型。纯分页段不参与正文文本顺序计数，但其分页仍逐段受审计。
4. 编号前缀中的书签仍包围新生成的编号域，正文中的书签保留正文范围。无法安全消费前缀时保留原域，向结果报告明确 warning，避免静默丢失。
5. 原样复制的源原子记录元素位置与结构指纹，保存后独立回读核验。删除或改写 REF 域、公式、书签等对象会报 `retained_inline_changed`，不会因纯文本投影为空而漏检。
6. 格式审计只对来源记录和保存后指纹匹配的原子 run 豁免。相邻正文、未保留的生成字段、指纹不匹配的 run，以及源文件 review 消费者仍按原合同检查。

指纹读取 lxml 底层 XML text，避免 python-docx `CT_R.text` 的语义聚合影响结果。结构容器的排版空白允许保存重读归一，`w:t`、`w:instrText` 等叶子文本空格仍属于实质内容。
