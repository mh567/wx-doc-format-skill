# T01 题注序列标识符与域形态改为模板拥有

依赖：无。本包唯一工单。

## 背景

见 `README.md`。缺陷是输出把图表题注的 SEQ 标识符写成了硬编码的英文 `Table` / `Figure`，并且用简单域、标签后多一个空格，导致 Word 的交叉引用对话框列不出编号项。

## 工作项

### 1. 模板题注序列读取

`scripts/wxdf/template.py` 新增读取：扫模板 `word/document.xml` 的题注样式段落（样式由呈现契约的 `resolved_styles.caption` 定位），取出该段的 SEQ 标识符，写入呈现契约 `captions`：

```python
{"table_sequence": <str>, "figure_sequence": <str>, "source": "template" | "fallback"}
```

种类判定按标签优先、相邻块兜底：题注自身的段首标签（`表` / `图`）判为对应种类；标签不在 WX 词表内时才看相邻块（下一兄弟块是表格判表，前一兄弟块含图形判图）。模板解析不出题注样式时直接回落，不扫描正文。

SEQ 标识符的读取与标识符到种类的词表归 `scripts/text_utils.py` 单一所有者。

### 2. 题注写出改为模板形态

`scripts/wxdf/rendering.py::_write_caption`：

- 标识符改从 `normalized["presentation"]["template_contract"]["captions"]` 读取，删除 `_CAPTION_SEQUENCE` 硬编码表；
- 按模板 run 序列写复杂域：标签 run（无尾随空格）、`fldChar[begin]`、`instrText`（`SEQ <标识符> \* ARABIC`）、`fldChar[separate]`、缓存编号、`fldChar[end]`、正文 run（前导空格）；
- 返回值改为 `f"{标签}{编号} {正文}"`，与保存后文档的逐 `w:t` 文本一致，回读审计的文本比对不退化；
- 附录范围内保留源编号的题注分支不变。

### 3. 消费方与测试断言跟随

- `scripts/caption_placement.py::_rendered_caption_type` 走共享的标识符读取与词表，标签文本回落分支保留；
- `tests/test_native_semantic_ownership.py`、`tests/test_modular_fidelity.py`、`tests/test_modular_conversion.py`、`tests/test_modular_caption_consumption.py`、`tests/test_t05_mixed_content.py` 共 13 处断言改为模板标识符与复杂域；
- `tests/test_md_captions.py` 不改，它驱动 legacy 链路。

### 4. 治理文档同步

改写 `AGENTS.md` 决策 3：题注编号标识符与域形态取自模板自身的题注域，本模板为 `SEQ 表` / `SEQ 图`，不写死英文标识符。

## 红灯先行

先写 `tests/test_modular_caption_sequence.py`，在未改实现的工作树上确认失败项，再实现。实测初始为 `6 failed, 1 passed`。夹具修正一处：图题注按 WX 约定放在图片下方，第一版夹具放在上方导致只重建了表题注。

## 未关闭时的处置

若模板读取在某种题注排布下无法判定种类（例如题注与对象之间夹了其它块），停止实现并把该形状写入 `README.md`，交用户裁定；不允许在无证据时默认按标签文本猜测。
