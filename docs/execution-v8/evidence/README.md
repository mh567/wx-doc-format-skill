# 本包证据约定

每个工单一份 `T<nn>.md`，内容固定为四节：

1. **红灯**：未改实现时的测试计数与逐项失败清单，附命令。
2. **绿灯**：实现后的专项与全量计数，附命令。
3. **样例矩阵**：逐份输入的实测结果，写明状态、三项审计、`unexpected_styles`、`risk_warnings`，以及与本工单相关的逐项输出事实（题注 run 序列、SEQ 标识符统计）。
4. **独立审查与复审**：Standards 轴与 Spec 轴各一条结论列表，逐条标注已修 / 记录为残留 / 需用户裁定，附复审后的计数。

涉及无法在本机验证的外部行为（例如 Word/WPS 的交叉引用对话框）时，证据必须写明「本机不可验证」，并把人工确认列为外部门禁，不允许把未验证的行为写成已验证。

证据只记录实际命令的实际输出。未关闭项在证据文件中单列，并同步回 `status.json` 的 `residuals`。本包状态唯一源是 `../status.json`。
