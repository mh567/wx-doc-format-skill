## 规格与实现的偏差（已记录）

规格的解决方案写「按相邻块判定种类（下一兄弟块是表格即为表题注，前一兄弟块含图形即为图题注）」。实测模板的 4 条带域题注中，`图1` 那条的前一兄弟块不含图形（图片在两张注段落之前，中间隔了 2 个块），该规则单独用不足以配对。实现改为三级判据：下一兄弟块是表格判为表题注；前一兄弟块含图形判为图题注；两者都不成立时用题注自身的段首标签（`表` / `图`）配对。模板 4 条题注据此全部配对成功，`source` 为 `template`。

## 独立审查与复审

审查由另一智能体执行（`git --no-pager diff`、`pytest tests/ -q`、模板与输出的域比对，另在 `$COMMANDCODE_SCRATCHPAD` 写探针）。结论：无阻断项，可落地。逐条处置：

- **F1（潜在缺陷，已修）**：`resolved_styles.caption` 解析不出时 `style_id` 为 `None`，过滤条件 `!= style_id` 会把每个没有 `w:pStyle` 的段落当成题注段落，从而读到无样式段落里的任意 `SEQ` 域。已加守卫：解析不出题注样式时直接回落，不扫描正文。新增 `test_a_template_without_a_caption_style_reads_no_field`，并用「无题注样式的模板加 `SEQ 自定义`」复现：修复前取到 `自定义`，修复后为 `表` / `图`。
- **F2（潜在缺陷，已修）**：相邻块判据排在标签之前，导致「标签为 `图` 的题注紧跟表格」会把图的标识符写进 `table_sequence`。已把标签提为首要判据、相邻块降为兜底。复现：标签 `图`、标识符 `图解`、下一块是表格，修复后为 `figure_sequence='图解'` 且 `table_sequence` 回落 `表`；新增 `test_a_caption_label_decides_its_kind_before_the_next_block`。
- **F3（规格表述，已修）**：规格正文与两处 docstring 把相邻块写成主要判据，而模板自身的 `图1` 题注由标签决定（图片在两张注段落之前，不在相邻位置）。规格的解决方案与 T01 工作项 1、以及 `template.py`、`rendering.py` 的 docstring 都已改写为「标签优先、相邻块兜底」。
- **F4（单一所有者，已修）**：SEQ 标识符读取与「标识符到种类」词表原先在 `template.py` 与 `caption_placement.py`/`rendering.py` 各有一份。已收敛到 `scripts/text_utils.py` 的 `sequence_identifier` 与 `CAPTION_SEQUENCE_KINDS` / `CAPTION_SEQUENCE_FALLBACK`，三处消费共用。
- **F5（规格自相矛盾，已修）**：规格把 `tests/test_md_captions.py` 列入「消费方跟随」，该用例实际驱动 legacy 链路、英文标识符断言在那里仍成立。README 与 T01 已改为「不改」并说明理由。
- **F6（覆盖缺口，已修）**：规格的 8 条测试决策只落地 7 条。已补 `input/benchmark_report.md` 回归用例与公式域保真用例（用模板同形的复杂域构造）；真实文档的标识符统计明确记为证据而非测试集（该文件在仓库之外）。现为 11 项。
- **F7（既有缺陷，未修，记为残留）**：题注若携带带 `cached_result` 的 `opaque_inline` 原子，`_text` 与 `starts` 复制路径会各算一次，返回值与保存段落文本可能不一致。该逻辑不在本包 diff 内。我用简单域夹具复现了同类漂移（源段落含 `w:fldSimple` 时 `paragraph.text` 读不到缓存结果，回读审计报 `paragraph_order_changed`），并用 `git stash push -- scripts` 回到 HEAD 复跑，**结论相同**，确认为既有缺陷、与本包无关。复现脚本：`$COMMANDCODE_SCRATCHPAD/simple_field_probe.py`。
