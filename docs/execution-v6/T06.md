## 工作

1. 重启、指定起始值、同级继续编号的建模。
2. 同一逻辑列表被拆成多个 numId 时合并为同一序列;不同逻辑列表复用同一 numId 时拆开。
3. 编号定义缺失或损坏时降级为受控正文并保留原文证据。
4. 子列表随父项重启、跨父项继续两种策略。
