## 工作

1. 在 `parsers.py` 实现原生 DOCX 编号目录,替代对旧 `list_detector._numbering_maps / _level_values` 的依赖:`pStyle→段落样式` 继承(段落样式 `numPr` 的 `ilvl` 按规则忽略,实际层级由 `w:lvl/w:pStyle` 关联确定)、`lvlRestart`、`startOverride`、编号级 `w:ind`、`suffix`、`abstractNumId` 与缺失/损坏编号的诊断降级(保留原文证据,进入 `downgrades`)。`visible_list_marker` 与自动编号并存时双通道保留。
2. `contracts.py` 登记新证据字段与列表语义合同版本。
3. `lists.py` 扩展证据字段与候选结构:`source_ilvl / effective_ilvl / semantic_level / render_level` 分开保存;`start_value / sequence / restart_scope` 替代布尔 `restart`;`list_item_map` 继续由附录复用。
4. `source_ast.py` 列表项 `content_blocks` 可拥有 `paragraph / table / image / quote / code / formula / note`;沿用嵌套 list 容器树。
5. 语义模块输出新增字段,不破坏既有 `list_semantics_result / candidates / list_semantics / list_item_map` 接缝。
