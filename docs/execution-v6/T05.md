# T05 列表项混合内容

## 分工

Codex 定内容归属模型;Claude 实施;Codex 独立审查及复审。

## 范围

- `scripts/wxdf/semantics/lists.py`
- `scripts/wxdf/semantics/source_ast.py`
- 对应测试与 `evidence/T05.md`

## 依赖

T04。

## 工作

1. 列表项 `content_blocks` 允许 `paragraph / table / image / quote / code / formula / note`。
2. 子列表后的续接正文归属回正确的列表项(`owner_item_id`)。
3. 沿用 `list_item_map` 接缝,让附录/表格/题注/结构语义模块读取同一归属。

## 验收

- 含混合内容的列表项归属正确(表格/图片/引用/代码都挂在正确项下)。
- 失败样例库中「列表项含续接正文 / 嵌套表图」红灯转绿。
- 全量测试通过。
