## 工作

1. 深层项必须有前置父项,层级逐级递增,列表类别与层级相互独立。
2. 处理 `numId+ilvl=0` 子表:按全局约束识别为子级而非同级项。
3. 处理父项缺失或滞后(源文档子项先于父项)的降级与诊断,不再静默挂到最近父项。
4. 覆盖多层有序嵌套、多层无序嵌套、有序无序交叉嵌套、列表穿插正文嵌套。

- 失败样例库中「多层嵌套 / 交叉嵌套 / 穿插正文」红灯转绿。
- 全量测试通过。
