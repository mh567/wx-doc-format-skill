## 合同覆盖

- Source AST 仍是唯一语义读取来源，规范化函数不写入输入 AST。
- 模板 profile 只提供能力和呈现映射，角色不由模板样式名重新判定。
- marker_anchor、target_sequence、target_level、marker_kind 和 target_ordinal 均进入 presentation 节点。
- 生成承载节点带 generated_by 和 generation_basis，未伪造源位置。
- `semantic_digest` 与 `presentation_digest` 可分别判断语义和呈现变化。
