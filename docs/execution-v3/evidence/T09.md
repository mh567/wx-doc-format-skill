## 合同覆盖

- `--pipeline modular --llm-enhance off` 显式运行纯规则路径，默认仍是 legacy。
- modular 不接受在线增强、请求生成和恢复，阻断状态带退出码 2，未生成 DOCX。
- 私有模式可写 Source AST 和 Normalized AST，release 模式继续拒绝完整 AST 导出。
- 多文件发布先写 staging，再逐文件提交和写入 manifest、COMMITTED，恢复检查以摘要为准，不声称多路径单次原子替换。
- 真实 Markdown 转换、保存、DOCX 回读和嵌套列表均有测试证据。
