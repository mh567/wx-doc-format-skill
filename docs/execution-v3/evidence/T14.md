## 实际改动

- `scripts/wxdf/semantics/tables.py`
  - 记录 data、code_sample、callout、layout 和 unknown 类型。
  - 对 layout 表保存源宽度、边距、行高、边框和 autofit 合同。
  - 数据表题注资格和表格结构审计独立输出。
- `scripts/wxdf/semantics/captions.py`
  - 校验表题在表上方、图题在图下方的关联位置。
  - 题注文本写入带目标内容摘要、关联摘要、revision 和能力版本的 Overlay。
  - 目标内容或题注关联变化会使 Overlay 失效。
- `scripts/wxdf/semantics/appendices.py`
  - 根据 appendix 容器和标题源证据识别范围。
  - 生成相对一至三级标题层级，保留 A.1 源编号证据并记录分页边界。
  - 对 nested main numbered heading 保存负证据，避免误开启附录范围。
- `scripts/wxdf/semantics/__init__.py`
  - 导出表格、题注和附录语义模块。
- `tests/test_modular_semantics.py`
  - 覆盖表格 layout、caption eligibility、题注 Overlay 失效、表图位置、附录层级和分页边界。

## 合同覆盖

- layout 表不进入普通 data 表格格式合同，源尺寸和无框线信息保留在显式 layout contract。
- 新题注文本只进入 Overlay，Source AST 内容事实保持不变。
- 表题和图题位置由关联审计验证，题注类型和目标类型保持一致。
- 附录范围包含唯一显式分页边界和相对层级派生结果，源题注编号证据不被覆盖。
