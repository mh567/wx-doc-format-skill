## 合同覆盖

- Markdown 与 DOCX 事实使用同一个 `analyze_lists()` 消费入口。
- 源标记、源序列和源深度与目标编号计数分离，源跳号和目标展平不会互相覆盖。
- 容器父项通过结构或有界深度证据确定，缺失证据保持 unresolved，未虚构父项。
- 保护内容、空列项、续段和局部作用域均保留为关系结果或诊断，未把单个数字前缀直接升级为列表。
