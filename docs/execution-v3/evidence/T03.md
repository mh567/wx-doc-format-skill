## 合同覆盖

- Markdown 通过 `markdown-it-py` token 流生成稳定的 units、list/list_item 容器、行内 text、link、image resource、代码和 opaque 诊断。
- DOCX 通过 OOXML body、编号描述、表格行列和关系部件生成公共事实，保留 `twips` 缩进量纲及 numbering definition 引用。
- 两种输入都使用同一个 `summarize_source_facts()` 公共消费者；独立假 parser 只需返回 SourceFacts 合同即可复用。
- SourceStore 单次打开源包，DOCX part 与 Markdown 文本按 source snapshot 读取，引用解析拒绝跨快照访问。
- 同一输入重复解析产生相同 JSON 事实，资源与诊断进入声明字段，未把未解析内容静默丢弃。
