# T01 Kernel 静态方法归位

## 分工

由 Command Code 协同多个智能体实施；接口与落点由架构智能体定案，实现与定向测试由一个智能体承担，独立审查与复审由另一个智能体承担。

## 范围

- `scripts/wxdf/kernel.py`
- `scripts/wxdf/registry.py`
- `scripts/wxdf/decision_ledger.py`
- `scripts/wxdf/checkpoint_store.py`
- `scripts/wxdf/parsers.py`
- 对应测试与 `evidence/T01.md`

## 依赖

无。

## 工作

1. 删除无调用方的 `_native_should_block_publish`，实际检查已在 `native_stages.py` 内联。
2. 删除兼容静态方法 `_facts_to_ast`、`_materialize_list_semantics`，测试改为直接驱动 `semantics/source_ast`。
3. `_native_source_type` 移入 `parsers`。
4. `_native_preflight`、`_native_execution_plan_report`、`_native_capability_status`、`_native_checkpoint_modules` 移入 `registry`。
5. `_native_ledger_replay_report` 移入 `decision_ledger`。
6. `_lock_native_checkpoint_identity` 移入 `checkpoint_store`。
7. `_native_v2_run_result` 按 artifact owner 拆分，kernel 只保留 lifecycle。

## 验收

- kernel 仅含 `convert`、`_convert_modular_native_v2`、异常分流与发布触发。
- 不存在 `_native_should_block_publish`、`_facts_to_ast`、`_materialize_list_semantics` 等已迁移符号。
- 每项翻译在 owner module 的 interface 上可测，测试不再经 kernel 私有方法。
- 全量测试通过，真实 Markdown 与真实 DOCX 转换结果不变。

## 红灯

新增断言 kernel 不再暴露上述静态方法，且 owner module 提供等价行为的测试。初始运行应失败。
