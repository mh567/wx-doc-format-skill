# T05 Digest owner

## 实施摘要

canonical JSON 加 sha256 的身份规则收敛到唯一 owner `scripts/wxdf/digest.py`。七个 module 的本地副本删除，改为 import 该 owner。产出的 canonical 文本与 `sha256:<hex>` 摘要字符串保持不变，因此 checkpoint 中存放的摘要仍可比较。

### 新增 owner：`scripts/wxdf/digest.py`

- `canonical_json(value)`：`json.dumps(value, ensure_ascii=False, sort_keys=True, separators=(",", ":"))`。
- `digest_hex(value)`：对 `canonical_json(value)` 取裸 sha256 十六进制，供需要裸摘要作 id 后缀的调用方使用。
- `digest(value)`：返回 `sha256:<hex>`，即共享内容身份。

### 生产代码

- `checkpoint_store.py`：删除本地 `_canonical` 与 `_digest`，改为 `from .digest import canonical_json, digest`。六处 `_canonical` 调用点改为 `canonical_json`，二十处 `_digest` 调用点改为 `digest`。`file_digest`、`_bytes_digest` 属于对原始字节取摘要，与规则无关，保持原样。
- `transaction.py`：删除本地裸十六进制 `_digest`，改为 `from .digest import digest_hex`。`transaction_content_digest` 仍在前面拼接 `sha256:`，`_transaction_id` 仍使用裸十六进制。移除因此不再使用的 `import hashlib` 与 `import json`。
- `validation.py`：删除本地 `_canonical_digest`，改为 `from .digest import digest`，三处调用点改为 `digest`。`_HASH_PREFIX` 仍由 `_sha256` 使用，保留。移除不再使用的 `import hashlib` 与 `import json`。同步把 `validate_checkpoint` 中 `for transaction_id, digest in ...` 的循环变量改名为 `stored_digest`，避免遮蔽新导入的 `digest`。
- `enhancement.py`：删除本地 `_digest`，改为 `from .digest import digest`。三处调用点原先先 `_thaw` 再规范化，现有调用点传入的都是已解冻的普通 dict 与 list，`digest` 产出完全一致。移除不再使用的 `import hashlib`。
- `decision_ledger.py`：删除本地 `_facts_digest`，改为 `from .digest import digest`，`source_binding` 调用 `digest(facts)`。`_legacy_transaction_digest` 不排序键名，属于另一条 legacy 规则，保留。
- `review.py`：删除本地 `_content_digest`，改为 `from .digest import digest`，`evaluate_candidate` 的 content 比较改为 `digest(_content_surface(bundle))`。移除不再使用的 `import hashlib` 与 `import json`。
- `response_store.py`：`content_digest` 保留在本 module 定义，函数体从转发 `checkpoint_store._digest` 改为调用 `from .digest import digest`，`test_modular_ac3` 的归属断言仍成立。
