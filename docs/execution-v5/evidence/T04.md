# T04 删除 facade 与注入面收敛

## 实施摘要

生产调用不再经 `sys.modules` 名字回查，`builtin_modules` 与 `run_store` 两个 facade 已删除，调用图静态可见。

### 生产代码

- `semantic_modules.py`：删除 `_compat` 与 `compatibility_hook` 以及仅供其使用的 `import sys`。`source_facts_module` 直接调用 `parse`。`build_native_candidate_baseline` 的每个 `_compat("X", X)` 调用点改为直接引用模块级名字 `X`，`__all__` 去掉 `compatibility_hook`。签名自省逻辑保留，测试替身仍可注入更少形参的 builder。
- `native_stages.py`：删除 `compatibility_hook` 导入，`_native_candidate_set` 直接引用模块级 `collect_native_candidates`。
- `checkpoint_store.py`：删除 `_compat_replace_bytes` 与 `import sys`，三处调用点改为本模块的 `_replace_bytes`。`_replace_bytes` 保留为真实函数。`prepare_native_resume` 直接调用 `build_native_candidate_baseline`，去掉兼容钩子。
- `kernel.py`：checkpoint 相关导入由 `.run_store` 改为 `.checkpoint_store`，即真实的 owner。
- 删除 `scripts/wxdf/builtin_modules.py` 与 `scripts/wxdf/run_store.py`。`run_store` 原先仅是 `checkpoint_store` 与 `response_store` 的转发门面，其符号在 `checkpoint_store` 中已存在并由其 `__all__` 重新导出。

### 注入面

- `semantic_modules` 的候选构造改为 patch `semantic_modules.<name>`，链式阶段改为 patch `native_stages.collect_native_candidates`。
- checkpoint 落盘竞态注入改为 patch `checkpoint_store._replace_bytes`，`os.replace` 注入改为 patch `checkpoint_store.os.replace`。
- resume 的 prepare 注入改为 patch `checkpoint_store.prepare_native_resume`，因为 kernel 在调用时从 `checkpoint_store` 绑定该名字。
- 逐测试迁移保持原意图：共享 collector、live baseline drift、resource 消失、append 竞态、锁住最终 replace、fcntl 缺失导入。
