# T04 删除 facade 与注入面收敛

## 分工

由 Command Code 协同多个智能体实施；注入面由架构智能体定案，实现与定向测试由一个智能体承担，独立审查与复审由另一个智能体承担。

## 范围

- `scripts/wxdf/builtin_modules.py`（删除）
- `scripts/wxdf/run_store.py`（删除）
- `scripts/wxdf/semantic_modules.py`
- `scripts/wxdf/native_stages.py`
- `scripts/wxdf/checkpoint_store.py`
- `scripts/wxdf/kernel.py`
- 测试注入点（4 个文件，约 40 处）
- 对应测试与 `evidence/T04.md`

## 依赖

无。

## 工作

1. 删除 `semantic_modules` 的 `_compat` 与 `compatibility_hook` 动态回查，改为直接 import。
2. 删除 `builtin_modules.py` 与 `run_store.py`。
3. 测试 monkeypatch 由按名字回查改为 patch 消费方 module 里的名字，例如 `semantic_modules.analyze_lists`、`native_stages.build_source_ast`。
4. `_replace_bytes` 作为 `checkpoint_store` 的真实函数保留，竞态注入改为 patch 该单一符号。
5. `os.replace` 注入改为 patch 拥有它的 module 属性。

## 验收

- 不存在 `sys.modules` 名字回查。
- 调用图静态可见。
- 崩溃与竞态注入测试仍通过。
- 全量测试与真实转换通过。

## 红灯

断言删除 `builtin_modules`、`run_store` 后导入成功，且生产调用不依赖它们。初始运行应失败。
