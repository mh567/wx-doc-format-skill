# T07 Checkpoint 拆分与 response_store seam

## 分工

由 Command Code 协同多个智能体实施；模块边界由架构智能体定案，实现与定向测试由一个智能体承担，独立审查与复审由另一个智能体承担。

## 范围

- `scripts/wxdf/request_append.py`（新增）
- `scripts/wxdf/checkpoint_store.py`
- `scripts/wxdf/response_store.py`
- 对应测试与 `evidence/T07.md`

## 依赖

T04、T05、T06。

## 工作

1. 抽出 request-append journal（跨进程锁与 write-ahead 恢复）为 `wxdf/request_append.py`。
2. 撤销 `checkpoint_store` 对 `response_store` 的反向 re-export 与文件底部 lazy import。
3. `response_store` 只依赖 `checkpoint_store` 的公开 API，不触碰私有函数。
4. legacy digest 迁移作为隔离的私有 helper 保留在 checkpoint 内。
5. persistence 与 `prepare_native_resume`、`complete_native_checkpoint` 仍作为 `checkpoint_store` 的深 interface。

## 验收

- journal 为独立可测 module。
- 无反向 re-export 与 lazy import cycle。
- `response_store` 不触碰 checkpoint 私有符号。
- 文件协议、恢复与幂等测试通过。

## 红灯

断言 `response_store` 不导入 checkpoint 私有符号，且 journal 独立可测。初始运行应失败。
