# T06 事务证明收敛

## 分工

由 Command Code 协同多个智能体实施；证明 owner 与接口由架构智能体定案，实现与定向测试由一个智能体承担，独立审查与复审由另一个智能体承担。

## 范围

- `scripts/wxdf/decision_ledger.py`
- `scripts/wxdf/transaction.py`
- `scripts/wxdf/checkpoint_store.py`
- `scripts/wxdf/response_store.py`
- 对应测试与 `evidence/T06.md`

## 依赖

T04、T05。

## 工作

1. 证明的构造与校验收进 `decision_ledger`，它是账本、response 与 checkpoint 三者的共同锚点。
2. `transaction` 导出纯判定函数 `revision_applied`，取代 `decision_ledger._revision_applied` 对 `transaction._apply_*` 的正向重演。
3. `checkpoint_store` 与 `response_store` 的证明片段改为调用 ledger owner。

## 验收

- 证明只有一处 owner。
- apply 语义只有一个来源，操作改动只需改一处。
- 账本重放与恢复测试通过。

## 红灯

断言 ledger 不再自带 apply 语义重演，而是调用 transaction 的判定函数。初始运行应失败。
