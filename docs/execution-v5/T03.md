# T03 保护策略 owner

## 分工

由 Command Code 协同多个智能体实施；策略归属由架构智能体定案，实现与定向测试由一个智能体承担，独立审查与复审由另一个智能体承担。

## 范围

- `scripts/wxdf/semantics/protected.py`
- `scripts/wxdf/semantics/lists.py`
- 对应测试与 `evidence/T03.md`

## 依赖

T02（两票都改 `lists.py`）。

## 工作

1. `protected_unit_semantics` 成为保护策略的唯一 owner。
2. `lists.py` 删除重复的 `_is_protected` 正则，改为 import。
3. 删除重复的日期、版本、API、手工标题与代码样式规则常量。

## 验收

- 保护策略只有一处实现。
- `lists` 不携带重复正则。
- 回归测试覆盖：同一输入下列表保护与 protected content 裁决一致，且 `lists` 不再定义策略常量。

## 红灯

断言 `lists` 与 `protected` 对同一输入给出一致裁决，且 `lists` 不再定义策略常量。初始运行应失败。
