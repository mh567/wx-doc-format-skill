# wx-doc-format-skill

## 核心能力

将 Markdown 或 DOCX 文档转换为 WX 模板格式的 DOCX，自动处理标题、目录、列表、表格、题注和附录，并生成审计报告。

运行时使用本机编译包，目标机无需安装 Python。当前发布目标为 macOS ARM64 和 Kylin V10 ARM64。macOS 制品经最低系统版本校验后进入 accepted 状态。Kylin V10 ARM64 制品保持 candidate 状态，启动时输出 `WXDF-W-RUNTIME-CANDIDATE` 后继续执行。

## 安装方法

对支持 Skill 的 Agent 说：

> 从 GitHub 仓库 mh567/wx-doc-format-skill 安装 wx-doc-format skill

安装完成后可直接通过对话触发。首次转换会先读取 manifest 中的平台状态，再获取当前平台制品、验证 SHA256 并完成本地安装，无需手工执行命令或配置环境变量。状态 unavailable、缺失、未知或损坏时以退出码 3 停止，且不会开始下载或执行缓存运行时。

内网离线部署时，从 GitHub Release 或内网介质取得对应平台的完整 Skill 安装包，直接交给 Agent：

> 安装这个 wx-doc-format 离线 Skill 包

Agent 解压后将包含 `SKILL.md` 的完整目录安装到自身 skills 目录。安装包已包含模板、启动脚本和本机运行时，安装和首次转换都无需下载文件或配置环境变量。

## 使用方法

上传文档，并在对话里说明要做哪一种。Agent 未确定时请用户四选一，用户已说明时直接执行。

| 选项 | 触发说法 | 产物 |
|------|----------|------|
| 普通格式转换 | 技术文档格式、转换为技术文档格式、按技术文档格式排版、整理成技术文档、wx文档格式、WX 格式转换 | 模板化 DOCX 与审计报告 |
| AI 增强格式转换 | 以上任一说法，另加“LLM 增强模式” | 同上，转换前用 LLM 复核目录区域、列表识别与题注 |
| 普通格式审查 | 审查这个文档的格式、检查文档是否符合模板要求、格式审查、文档格式检查、给这个文档的格式打分、生成格式整改报告 | 百分制评分与整改报告，完全离线 |
| AI 增强格式审查 | 以上任一说法，另加“AI 增强” | 同上，另加引用文件排序、术语与缩略语、列项用法的语义检查 |

转换接受 Markdown 或 DOCX，审查只接受 DOCX。示例：

> 技术文档格式，请处理这个附件。

> wx文档格式，请把附件转换成标准格式。

> 使用 wx文档格式的 LLM 增强模式处理这个 Markdown。

> 审查这个 DOCX 是否符合模板要求，给出评分和整改建议。

> AI 增强格式审查附件里的文档。

四种模式：

1. 普通格式转换：本地确定性处理，适合结构清晰的文档。
2. AI 增强格式转换：增加模糊目录复核、语义列表识别、题注生成和审计后受限复核。
3. 普通格式审查：按格式合同比对元素格式，覆盖样式与元素格式、大纲层级、列表结构、表格格式合同、目录、附录、题注、注、页码与编号九个维度，逐项给出问题分级与整改建议。
4. AI 增强格式审查：在普通审查之上增加引用文件排序、术语与缩略语、列项用法三项语义检查。

转换完成后返回 DOCX，并说明审计结果和需要人工复核的项目。审查完成后返回评分、问题分级与逐项整改建议。普通模式与普通审查不需要任何模型，两个 AI 模式需要代理提供模型响应。
